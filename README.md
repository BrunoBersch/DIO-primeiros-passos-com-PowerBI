📊 Dashboard Financeiro em Power BI
Este projeto apresenta um dashboard interativo desenvolvido no Power BI utilizando o conjunto de dados de exemplo Financial Sample fornecido pela Microsoft. O objetivo é demonstrar a capacidade de análise visual de dados financeiros e comerciais, com foco em indicadores de desempenho por segmento, produto, país e período.

📌 Objetivos do Dashboard
Visualizar o desempenho financeiro por país e segmento

Identificar os produtos mais lucrativos

Acompanhar a evolução da receita e lucro ao longo do tempo

Facilitar a tomada de decisão com base em dados visuais

🛠️ Ferramentas Utilizadas
Power BI Desktop: Para criação do dashboard

Microsoft Excel: Fonte dos dados (.xlsx)

DAX: Para criação de medidas e cálculos personalizados

📈 Visão Geral do Dashboard
O dashboard inclui:

Gráficos de barras e colunas para comparação de receita e lucro

Mapas para visualização geográfica por país

Segmentações por produto, segmento e período

Indicadores de desempenho (KPIs)
